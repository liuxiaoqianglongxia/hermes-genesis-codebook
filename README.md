# Hermes Genesis Codebook

这是「麦尖AI」Hermes Genesis 第一季的公开配套仓库。

它不是 Hermes 官方源码，也不包含任何本机私有配置。

这里放的是连载里反复踩坑后整理出来的可复制骨架：

- 基础文件治理模板
- 单实例总控多团队骨架
- 角色档案与角色记忆模板
- 子代理限制规则
- 第一季文章索引

## 全季概览

Season 1 共 15 篇：

| 类型 | 篇数 | 说明 |
|---|---|---|
| 官宣 | 1 | 系列定位与读者预期 |
| 故事主线 | 12 | EP-001 ~ EP-012 |
| 源码放送 | 2 | Code Drop 01（基础包）、Code Drop 02（工作台骨架） |

最终源码入口在本仓库。

## 四个 Release 的边界

**不要一上来就下 v1.0.0。按你的需求选：**

| Release | 对应阶段 | 适合谁 | 包含什么 |
|---|---|---|---|
| **v0.1.0-foundation** | EP-001~EP-003 | 只想让 AI 不乱放文件 | 术语表、目录规范、STATE.md 模板、progress.md 模板、registry.yaml 示例、config.yaml 导航层片段 |
| **v0.2.0-workbench** | EP-004~EP-009 | 想让一个 AI 管多个团队 | team-registry.yaml、team-boss 规则、上下文注入脚本、子代理限制说明 |
| **v0.3.0-role-memory** | EP-006~EP-007 延伸 | 需要角色档案和记忆系统 | 角色档案模板、记忆桶样例、注入示意、角色记忆闭环脚本 |
| **v1.0.0-season1-bundle** | 全季收束 | 想要最终整理版 | 全季文章索引 + v0.3.0 脚本打包 |

注意：v0.2.0 不包含角色档案和角色记忆，它们在 v0.3.0 中。这是有意的分层设计——先跑通总控骨架，再上角色系统。

## 适合谁

- 正在用 AI Agent 做真实项目的人
- 想把多团队协作收进一个主控实例的人
- 不想每次新会话都重新解释项目背景的人
- 想让角色经验能持续沉淀，而不是停在 Prompt 模板的人

## 不适合谁

- 想找一个下载即用的完整商业系统
- 不愿意整理本地文件结构
- 不愿意维护事实源和角色记忆

这套东西不是魔法。

它更像施工图。

你得按自己的项目慢慢改。
