# 知识库总入口

本目录存放系统全局规范，所有团队和角色共享。

## 目录结构

```text
knowledge/
  README.md              ← 本文件，知识库总入口
  standards/
    01-terminology.md    ← 术语与总纲（系统内所有概念的定义）
    02-structure.md      ← 目录结构规范（文件该放哪）
  teams/
    team-registry.yaml   ← 团队边界清单（有哪些团队、各自负责什么）
    <团队名>/
      charter.md         ← 团队章程
```

## 使用规则

1. 新会话启动时，先读本文件，再按 standards/ → teams/ 的顺序加载。
2. 不要把所有内容塞进一个文件。术语归术语，结构归结构，团队归团队。
3. 发现规范冲突时，以 standards/ 下的文件为准，项目内的旧文件不覆盖新规范。

## 最小验证

创建完目录后，新开一个会话，让 AI 回答以下问题：

- 术语表在哪？
- 目录结构是什么？
- 项目清单在哪？

如果它能准确回答，说明导航层生效了。
